## 🔄 Development Workflow

### Making Changes

1. **Update components** in `components/` folder
2. **Run locally**: `npm run dev`
3. **Test in browser**: `http://localhost:3000`
4. **Verify dark mode**: Toggle theme button
5. **Check mobile**: DevTools mobile emulation
6. **Commit changes**: `git add . && git commit -m "message"`
7. **Push to GitHub**: `git push origin main`
8. **Automatic deployment**: Vercel deploys automatically
